# MagicUI Design System Skill — Componentes UI Dark Mode de Ultra-Lujo

Esta habilidad establece las reglas de diseño frontend para construir interfaces SaaS de alto impacto visual con estética en tema oscuro (Slate 950 base), acentos violeta/índigo luminosos y micro-animaciones fluidas.

---

## 🎨 Paleta & Estilos Base

- **Background:** Slate 950 (`#020617`).
- **Cards & Containers:** Glassmorphism con bordes translúcidos (`border-white/10` y `backdrop-blur-md`).
- **Typography:** `Outfit` para encabezados comerciales y `JetBrains Mono` para contadores y datos.
