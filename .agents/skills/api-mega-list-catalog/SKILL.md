# API Mega List Catalog Skill — Directorio Maestro de APIs para Agentes

Esta habilidad integra el catálogo de APIs públicas y de desarrollo de **cporter202/API-mega-list** para acelerar la conexión de herramientas (*tool use*) en agentes de IA autónomos.

---

## 🛠️ Categorías Clave de APIs

1. **Fintech & Payments:** Pasarelas de pago, procesamiento de tarjetas, SPEI/PIX, datos bancarios.
2. **Identity & KYC:** Validación de identidad, verificación de documentos, AML y prevención de fraude.
3. **Data Enrichment & Scraping:** Extracción web, búsqueda de datos de contacto, enriquecimiento de empresas.
4. **Communication & Voice:** SMS, WhatsApp, mensajería, transcripción ASR (Whisper/Riva).
5. **AI & LLMs:** Providers, gateways de inferencia, embeddings y modelos vectoriales.
