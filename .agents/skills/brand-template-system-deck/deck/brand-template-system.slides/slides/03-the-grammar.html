03 · Methodology
The Atomic Design hierarchy
Five layers, smallest first.
Composition rule: a higher layer can only be built from layers below it. A new template is added only when it can be expressed as a new combination of existing molecules.[1][5]
Layer 01
Atoms
Indivisible tokens: a color, a type size, a spacing unit, a corner radius, a stroke weight.
