14 · Governance
How the system grows
A maintained system, not a published one.
Ungoverned systems decay. The system has a named maintainer, a public backlog, and an explicit contribution path.[4][6]
Step 01
Propose
Open a PR with the new atom, molecule, or template — expressed as JSON tokens plus one worked example slide.
Step 02
Justify
Show three real pages where the new component would have been used in the last quarter. No retroactive justification, no rejection.
Step 03
Review
Maintainer + two reviewers from a rotating panel. Decision in 5 working days. Status: accept, defer, fold-into-existing.
Step 04
Ship
Token bump, docs, change-log entry, and a Slack post in #brand-system. Minor → 1.x.y; new template → 1.x.0.
