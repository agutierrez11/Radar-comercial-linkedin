# Scroll Craft UI Skill — Narrativa e Interacciones Basadas en Scroll

Esta habilidad proporciona las herramientas para construir sitios web promocionales y dashboards donde el avance del scroll guía la narrativa del producto, revelando tarjetas, métricas y características clave.

---

## 🎯 Aplicación en Landing Pages

- Revelado secuencial de los 3 pilares del producto (Tesis BYOD, Modelo de Créditos y Zero-Knowledge Privacy).
- Animaciones fluidas utilizando `IntersectionObserver` y transformaciones CSS aceleradas por GPU.
