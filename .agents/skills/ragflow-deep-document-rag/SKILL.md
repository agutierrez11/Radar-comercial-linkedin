# RAGFlow Deep Document RAG Skill — Parseo Profundo de Documentos para IA

Esta habilidad integra las capacidades del proyecto open-source **infiniflow/ragflow** para la ingesta, lectura y recuperación semántica de documentos corporativos complejos.

---

## 🛠️ Capacidades Clave

1. **Deep Document Layout Parsing:** Extracción precisa de PDFs, contratos, hojas de cálculo de Excel y tablas complejas sin perder estructura.
2. **Hybrid Vector & Keyword Search:** Búsqueda semántica combinada con palabras clave para cero falsos negativos.
3. **Agentic RAG Workflows:** Pipeline de RAG interactivo con agentes para consultas financieras, legales y comerciales.
