# Gajae-Code Plan Harness Skill — Planificación Estricta & Control Remoto

Esta habilidad establece el patrón de arquitectura de **Gajae-Code**, obligando al agente a entrevistar, investigar y planificar rigurosamente antes de tocar código, evitando la "supervisión constante de terminal".

---

## 🛠️ Pilares Arquitectónicos

1. **Plan-Before-Mutation:** Investigación rigurosa de dependencias y generación de planes de implementación aprobados antes de modificar código.
2. **Multi-Model Routing:** Conexión agnóstica con múltiples proveedores de modelos (Claude, Gemini, Qwen).
3. **Remote Agent Control:** Monitoreo y control de sesiones agénticas mediante integraciones con Telegram, Slack o Discord.
