# Agent runtime brief — Pitch a Brand Event like IMG / Live Nation

## Core principle

the deck is sold on the moment a fan would film and the footprint that can deliver it. Logo-placement matrices, sponsor-tier ladders, and "Why us" agency-credentials slides belong in appendix or in a separate capabilities doc — never on a body slide.

## Context the agent must establish before generating

> Before producing the deck, the agent must know each item below.
> - If the user's prior messages already supply an item, use it; do NOT re-ask.
> - If an item can be reasonably inferred from the user's stated topic, infer it and state the assumption inline on slide 2.
> - Ask only what is missing AND cannot be inferred — one targeted question at a time, not a script.

1. **The property** — which festival, venue, tentpole, or rights-holder window (Coachella main lawn, Super Bowl week, US Open fan village, Art Basel Miami). Calibrates audience demos and the benchmark earned-media numbers the agent will cite on slide 4.
2. **The brand and the brand's one goal** — e.g. "e.l.f. wants Gen-Z beauty-tutorial UGC at scale", "Marriott wants high-net-worth check-in conversion", "Campari wants negroni-week social-first capture". The entire deck is shaped backwards from this one goal; if the user gives three goals, the agent forces a rank.
3. **The hero moment in one sentence** — what is the single thing a fan would film and post? If the user can't name one in one sentence, the activation isn't ready to pitch and the agent pushes back before generating the deck.
4. **Footprint band** — square footage, capacity-per-hour, open hours. The agent computes total touch on slide 5.
5. **Budget band** — total investment range. Used to apportion footprint / talent / media / contingency on slide 13.
6. *(optional)* **Talent integration** — named talent slots; the agent puts these on slide 9 as a separate line item, not bundled into "premium package".
7. *(optional)* **Reference activations** — Medicube Coachella 2026, Reddit "Find Your People", e.l.f. Brandchella — pulled into footnotes as benchmark.

## Mandatory checks (during generation)

- Slide 2 is the Moment, full-bleed render. No agenda slide before it. If the user supplies an agenda, the agent moves it to appendix and replaces slide 2 with the hero moment.
- Every activation has an Activation Proof Card naming hero moment, footprint, earned-media KPI, talent integration. Vague "increased engagement" / "premium placement" / "branded experience" lines are rewritten with a measurable KPI from the cited benchmark archive.[^8]
- Footprint math (capacity/hour × open hours = total touch) appears on slide 5, not in appendix. Numbers are shown, not described.
- Logo-placement matrices are demoted to appendix; never a body slide. The slide-1 cover and slide-2 Moment carry brand presence; the matrix is a contractual artefact, not a sales artefact.
- Talent and media are separate line items in the slide-13 investment breakout. Bundling them as "premium package" is flagged.
- Every external claim (Coachella 2026 numbers, Live Nation 10-K figures, Medicube benchmark) carries a footnote citation. Producer-side fact-checking happens before the room, not in it.
- Brand-safety, permits, insurance, and named production leads are on slide 14, not in a separate doc. CMO procurement reads this slide first; missing it costs the meeting.

## Template selection

- **Festival / Music** (default, bundled): main-lawn / brand-house shape, music-festival benchmark data, talent slots assume artist integration.
- **Sports tentpole** (alternate): Super Bowl / US Open / Formula 1 shape, hospitality-suite emphasis, talent slots assume athlete / commentator integration.
- **Cultural moment** (alternate): Art Basel / Cannes / Fashion Week shape, smaller footprint, press-and-creator-led earned media.
- **Award-show adjacency** (alternate): Met Gala / Oscars / Grammys week, hospitality + paparazzi-led capture, talent slots assume A-list-and-managers, contract-cycle measured in days not months.
