# LazyCodex Project Harness Skill — Memoria & Ejecución Verificada

Esta habilidad integra los patrones de diseño de **LazyCodex** para optimizar la navegación y modificación de grandes proyectos sin saturar la ventana de contexto de los modelos.

---

## 🛠️ Pilares Arquitectónicos

1. **Project Memory Management:** Indexación de contexto y mapa de dependencias del repositorio.
2. **Token Efficiency:** Optimización del consumo de contexto mediante resúmenes incrementales de Trajectory/Transcript.
3. **Empirical Completion Verification:** Cero declaraciones prematuras de éxito sin ejecutar pruebas o comandos de runtime.
