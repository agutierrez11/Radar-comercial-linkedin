# Langfuse LLM Observability Skill — Monitoreo & Control de Costos de IA

Esta habilidad define los estándares para instrumentar llamadas a LLMs, rastrear el consumo de tokens por usuario/inquilino (*multi-tenant*), evaluar la calidad de las respuestas y auditar latencias en aplicaciones agénticas.

---

## 🛠️ Métricas Core a Monitorear

1. **Token Usage & Cost:** Cálculo del gasto real por modelo (Gemini, Claude, GPT-4o, Qwen).
2. **Latency Tracking:** Tiempo de respuesta por llamada y paso agéntico.
3. **LLM-as-a-Judge Evaluation:** Evaluación automatizada de precisión y ausencia de alucinaciones.
